# Personal site of Jordan M. R. Fox, PhD, computational scientist

[Go to website](https://jmrfox.github.io/)

## Local preview

```bash
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Contact form

Messages go through [Formspree](https://formspree.io/); your inbox address is not stored in the HTML. Set `formAction` in `data/contact.json` to your form URL (e.g. `https://formspree.io/f/abcdefgh`).
