## Contact form

Messages are sent via [Formspree](https://formspree.io/) so your Gmail address is not in the HTML.

1. Create a free Formspree form and set the notification email to your inbox.
2. Copy the form URL (e.g. `https://formspree.io/f/abcdefgh`).
3. Paste it into `data/contact.json` as `formAction`, then deploy.

Local preview: `python -m http.server 8000` and open `http://localhost:8000`.
